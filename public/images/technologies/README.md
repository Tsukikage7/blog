# 关于页技术标识

- 自定义图片的官方来源见 `SOURCES.json`；图片存储于本站，避免访客加载外部图床。
- SVG 品牌标识使用已安装的 `react-icons/si`（Simple Icons），映射集中在 `src/lib/technologies.ts`。
- Hertz、Kitex、Eino 使用 CloudWeGo 官方标识；JetStream 使用 NATS 标识；Triple 使用 Apache Dubbo 标识；gRPC-Gateway 和 Reflection 使用 gRPC 标识。
- Wire、Fx、pgx、LuaJIT 尚未采用独立图标，保留项目官网或仓库文字链接；架构概念和协议不伪造品牌标识。
- 技能图标容器 24×24，图形 20×20；正文图标容器 16×16，图形 14×14；组织标识容器 48×48，图形 32×32。所有图片保持原始比例。

- 工作项目：VoyraCloud 使用官网 favicon；ALB、PathX 使用所属 UCloud 的官方品牌标识，分别链接到 ALB 内容转发文档和 PathX 产品页。
